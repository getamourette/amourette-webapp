# Use a French link preview for the Paris launch

Use one French title and description for search and link previews during the
Paris launch. The description names the city and explains how discreet likes
work. The people receiving the first shared links can understand the premise
before opening the site.

This supersedes the choice to reuse the English landing copy in
[the indexing decision](2026-11-26-search-indexing-deny-by-default.md).
All routes share the same preview, with the approved brand image and no details
about a specific venue, night or participant. Set the Open Graph locale to
`fr_FR` for that shared copy.
