Fonts, sources & what is still open

This is a real-font comparison, not generated lettering. The four supplied fonts are unmodified files from the official Google Fonts repository, with their licences preserved. Segoe fonts are not bundled: only local font lookup is attempted on your device, and no detection result is transmitted or saved.

Microsoft documents the distinction between Segoe UI, Segoe Print and Segoe Script. The page checks only these three families. Browser privacy restrictions can also prevent a local font from loading.

The identical figures and central heart are native SVG studies, not a platform emoji. Their drawing, proportions, colour, and minimum size are still open. Lettering is live SVG text using the named fonts, fitted by actual glyph bounds to a shared maximum width and height; it is not yet custom outlined lettering. The earlier serif lettering and its R are unchanged in the preserved references.
