Issue #39 · deployed review · September 8, 2026

The final application on Vercel.

The approved alignment is on the left; the current deployed application is on the right. Upstream corrections remove chat links from the returning landing and the duplicate logo from the first-entry reminder. Other logo placements retain the approved treatment. Open the alignment review.

Every personal and venue state is simulated. Profiles, illustrated portraits, venue, attendance and matches are synthetic. Application assets are served by Vercel. Browser Supabase calls and WebSockets are intercepted; no personal data is fetched or written. The server-side unsubscribe token check is read-only. Vercel’s review toolbar is excluded. The match is revealed through the real tap handler with a mocked response. Unsubscribe shows the actual invalid-link state without a token. The room email invitation uses an accelerated test clock to reach the existing two-minute prompt. These are screenshots, not an interactive app preview.

Captures use Chromium, English, 100% zoom and reduced motion for repeatability. Full-page images retain scrollable content; the listed height is the viewport, not necessarily the image height. At 320px, profile and age headers wrap the language control to preserve the 192px whole-file minimum. Existing display typography and onboarding remain unchanged.

Status: alignment preview approved; final PR delivery authorized. Physical phone/browser shortcut checks remain pending. This gallery records agent inspection of the deployed application, not founder approval of a new design or a physical-device test.
